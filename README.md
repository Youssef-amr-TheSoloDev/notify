# 🔔 Notify - Productivity App

A simple, clean, and lightweight productivity tool to manage your notes, tasks, and alerts — all in one place.

---

## About The Project

**Notify** is a front-end only productivity application designed to help you stay organized without the clutter. Whether you need to jot down a quick note, track your tasks, or set a reminder, Notify keeps it simple and distraction-free.

### Features

- Notes – Create, edit, and delete text notes instantly
- Tasks – Add tasks, mark them as complete, set priorities (Low/Medium/High), and optionally attach alerts
- Alerts – Set standalone alerts with visual notifications
- Dashboard – View all your counts, completion rates, and recent activity at a glance
- Search – Quickly find notes, tasks, and alerts
- Responsive – Works seamlessly on desktop and mobile devices
- Clean UI – Minimal and modern interface with smooth transitions

## Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (v18 or higher)
- npm (v9 or higher) or yarn
- Angular CLI (v17)

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/notify-app.git
   cd notify-app
   ```

2. Install dependencies

   ```bash
   npm install
   ```

   or

   ```bash
   yarn install
   ```

3. Run the development server

   ```bash
   ng serve
   ```

4. Open your browser
   Navigate to `http://localhost:4200`

## How It Works

1. Dashboard – Displays total counts for notes, tasks, and alerts, along with recent activity

3. Tasks – Add a task with priority level. Toggle completion status or delete tasks
4. Alerts – Create standalone alerts that trigger notifications
5. About – Learn more about the app and the development team

# مشروع Notify - تطبيق إنتاجية

تطبيق إنتاجية بسيط ونظيف وخفيف الوزن لإدارة ملاحظاتك ومهامك وتنبيهاتك - كل ذلك في مكان واحد.

---

## عن المشروع

**Notify** هو تطبيق إنتاجية يعمل على الواجهة الأمامية فقط، مصمم لمساعدتك على البقاء منظمًا دون تعقيد. سواء كنت بحاجة إلى تدوين ملاحظة سريعة، أو تتبع مهامك، أو تعيين تذكير، فإن Notify يبقي الأمور بسيطة وخالية من التشتت.

### المميزات

- الملاحظات – إنشاء وتحرير وحذف الملاحظات النصية بسرعة
- المهام – إضافة المهام، تعليمها كمكتملة، تحديد الأولويات (منخفضة/متوسطة/عالية)، وإرفاق تنبيهات اختيارية
- التنبيهات – تعيين تنبيهات مستقلة مع إشعارات مرئية
- لوحة التحكم – عرض جميع الإحصائيات، معدلات الإنجاز، والأنشطة الأخيرة بنظرة سريعة
- البحث – العثور بسرعة على الملاحظات والمهام والتنبيهات
- متجاوب – يعمل بسلاسة على أجهزة الكمبيوتر والهواتف المحمولة
- واجهة نظيفة – واجهة حديثة وبسيطة مع انتقالات سلسة

## 🧩 How It Works

1. **Dashboard** – Displays total counts for notes, tasks, and alerts, along with recent activity.
2. **Notes** – Add a note using the input field. Each note appears in a list with a delete option.
3. **Tasks** – Add a task. Toggle the alert checkbox to set a reminder. Mark tasks as done or delete them.
4. **Alerts** – Create standalone alerts. When added, a notification appears (simulated with a toast/modal).
